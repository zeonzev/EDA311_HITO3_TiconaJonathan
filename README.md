# EDA311_HITO3_TiconaJonathan

Aplicación web CRUD en **PHP + MySQL** para gestionar las tablas **clientes**, **pedidos** y **productos**, usando una **lista doblemente enlazada** y el algoritmo **Bubble Sort**.

Proyecto del HITO 3 de la materia **Estructura de Datos (EDA-311)** - UNIFRANZ La Paz.

> Proyecto en desarrollo. Este README se irá completando.

## Configuración de la conexión

1. Copiar `config/config.ejemplo.php` como `config/config.php`.
2. Completar los datos de conexión a la base de datos facilitada por el docente.

El archivo `config/config.php` no se sube al repositorio para no publicar credenciales.
